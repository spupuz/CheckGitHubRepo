    Dati in tempo reale dalle API di GitHub. Con token: GraphQL API (fino a 50 repo per richiesta, con draft/issue/età/reviewer). Senza token: REST API con header Link per il conteggio esatto delle PR. Limiti: 60 richieste/ora senza token, 5.000/ora con token; le richieste condizionali (ETag/304) non consumano quota. Draft, reviewer mancanti, PR ferme e autori sono calcolati sulle PR più vecchie campionate (fino a 50 per repo); i conteggi totali di PR e issue sono sempre esatti. Le variazioni confrontano l'ultima scansione salvata in questo browser. I grafici richiedono la connessione (ECharts via CDN). SQLite: ogni scansione viene registrata in un database in memoria (tabelle scans, repos, authors, labels); usa Scegli cartella per il salvataggio automatico dopo ogni scansione (Chrome/Edge), oppure Salva DB per scaricare il file nella stessa cartella del tool, e Carica DB per riaccumulare lo storico. Se questa anteprima blocca le chiamate esterne, scarica il file e aprilo nel browser.
