Open PR Checker

Scans all repositories of one or more GitHub accounts and shows, for each, the open pull requests with health metrics, charts, and a comparison against the previous scan. With a token it uses the GraphQL API and includes private repositories.

    Real-time data from GitHub APIs. With token: GraphQL API (up to 50 repos per request, with draft/issue/age/reviewer). Without token: REST API with Link header for exact PR counts. Limits: 60 requests/hour without token, 5,000/hour with token; conditional requests (ETag/304) do not consume quota. Drafts, missing reviewers, stale PRs and authors are calculated from sampled older PRs (up to 50 per repo); total PR and issue counts are always exact. Changes compare the last scan saved in this browser. Charts require a connection (ECharts via CDN). SQLite: every scan is recorded in an in-memory database (tables scans, repos, authors, labels); use Choose folder for automatic saving after each scan (Chrome/Edge), or Save DB to download the file to the same folder as this tool, and Load DB to accumulate history. If this preview blocks external calls, download the file and open it in the browser.
